# 🍜 Danny's Diner | SQL Case Study

## Overview

This is part of the **8 Week SQL Challenge**, created by Danny Ma (credits: [Danny Ma's 8 Week SQL Challenge](https://8weeksqlchallenge.com/case-study-1/))

In this project, I used PostgreSQL to answer business questions about customer purchases and the loyalty program performance.

## Dataset

We have three relational tables:

- `sales`: customer purchases and order dates.
- `menu`: product names and prices.
- `members`: loyalty program membership dates.

## SQL Concepts and Techniques used

- JOINs
- Aggregate functions and GROUP BY
- CTEs (Common Table Expressions)
- Window functions
- CASE expressions
- Subqueries
- Date calculations

## Personal Observation

I find this project interesting because, despite the small size of the dataset, it requires combining several SQL concepts to provide accurate answers to simple yet relevant questions.
